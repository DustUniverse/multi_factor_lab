## 新增测试规范

- 预期值要手算或使用可信小样本，不要凭感觉；
- 滚动窗口注意 `pct_change()` 引入的额外 NaN；
- MACD 暖机期为 `slow + signal - 2`；
- 新增因子必须同时新增对应单测；
- **阶段三新增**：
  - 合成权重“滚动到时点”必须有一个反例测试（用全样本 → 应当报错或被禁止）；
  - 引擎必须有一个“对照策略”单测：手算净值与引擎输出一致；
  - 绩效指标每个指标至少 1 个手算对照；
- 测试通过后再提交，提交信息可用 `test: ...`。

## 常见失败

| 现象 | 排查 |
|---|---|
| `ModuleNotFoundError: mfalpha` | 执行 `pip install -e .` |
| 预期值差 1 天 | 检查 `pct_change()` 与 `min_periods` |
| MACD 暖机期不符 | 暖机期是 `slow + signal - 2` |
| 财务对齐不符 | 检查是否按 `ann_date` 而非 `end_date` |
| 因子方向翻转后测试不符 | 翻转应在最终因子库阶段处理，不应改原始因子函数 |
| 引擎净值与手算不符 | 检查信号 / 成交是否用了同一日数据，或成本 / 滑点是否漏扣 |
| Lasso 测试结果抖动 | 固定随机种子；确认未随机打散；确认调仓日读取线性组 index |
| Backtrader 对账测试失败 | 先检查 symbol 是否统一 `astype(str).str.zfill(6)`，再检查日历 feed |
