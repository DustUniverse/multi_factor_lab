## 新增测试规范

- 预期值要手算或使用可信小样本，不要凭感觉；
- 滚动窗口注意 `pct_change()` 引入的额外 NaN；
- MACD 暖机期为 `slow + signal - 2`；
- 新增因子必须同时新增对应单测；
- **阶段三新增**：
  - 合成权重“滚动到时点”必须有一个反例测试（用全样本 → 应当报错或被禁止）；
  - 引擎必须有一个“对照策略”单测：手算净值与引擎输出一致；
  - 绩效指标每个指标至少 1 个手算对照；
- 测试通过后再提交，提交信息可用 `test: ...`。
- **阶段四新增**：
  - 绩效指标统一对齐 `engine.nav_stats`；年化使用 n-1 期收益率，至少 1 个手算对照。
  - M4c 测试与文档命名必须用“因子平滑（前视修正 + 系数/分数双层平滑）”，禁止出现“因子轮动”。
  - M4c 不得测成独立增量；应验证 `m4c_bt_periods` 与 `m4_final_periods` 逐行一致。
  - 验收 FAIL 不得通过改测试“修过”；Sharpe 1.5527 FAIL、日频 MDD -27.56% FAIL 必须保留。
  - `m3_rebuild_daily_nav.py` 的 Pandas `FutureWarning` 不作为测试失败项。

## 常见失败

| 现象 | 排查 |
|---|---|
| `ModuleNotFoundError: mfalpha` | 执行 `pip install -e .` |
| 预期值差 1 天 | 检查 `pct_change()` 与 `min_periods` |
| MACD 暖机期不符 | 暖机期是 `slow + signal - 2` |
| 财务对齐不符 | 检查是否按 `ann_date` 而非 `end_date` |
| 因子方向翻转后测试不符 | 翻转应在最终因子库阶段处理，不应改原始因子函数 |
| 引擎净值与手算不符 | 检查信号 / 成交是否用了同一日数据，或成本 / 滑点是否漏扣 |
| Lasso 测试结果抖动 | 固定随机种子；确认未随机打散；确认调仓日读取线性组 index |
| Backtrader 对账测试失败 | 先检查 symbol 是否统一 `astype(str).str.zfill(6)`，再检查日历 feed |
| 阶段四数字与 README 不一致 | 对齐 `engine.nav_stats`；年化 n-1；不要混用阶段三 53.69% 与阶段四 43.49% |
| M4c 被称为因子轮动 | 正名“因子平滑（前视修正 + 系数/分数双层平滑）” |
| 想把 M4c 当独立增量 | 检查 `m4c_bt_periods` 与 `m4_final_periods` 是否逐行一致；表述为“v2 分数在仓位之上叠加” |
| 为 Sharpe 1.680 改测试或调参 | 禁止；1.5527 FAIL 必须如实保留 |
| FutureWarning 导致测试报错 | 不影响数值，不修；确认不是 error 级过滤 |
