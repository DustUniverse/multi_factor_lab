# 阶段二 M6：牛熊 / 分板块稳健性检验总结

## 一、目的

在 M5 保留的 8 个因子上，检验其**在不同市场状态、不同上市板块下的有效性是否稳定**。
稳健性检验的目标不是"再筛掉因子"，而是**明确每个因子的适用边界**，为 M7 最终因子库提供依据。

## 二、方法与数据

| 项 | 说明 |
|---|---|
| 因子输入 | `factor_panel_selected.parquet`（8 因子，M5 产出） |
| 价格 | `daily_panel_tencent_clean.parquet`（1213 交易日 × 4853 只） |
| 市场状态 | 全市场等权指数的 120 日滚动收益，±10% 阈值：bull / flat / bear |
| 板块 | 价格面板自带 `board` 列：主板 / 创业板 / 科创板 |
| IC | 逐日 Spearman Rank IC，持有期 1D / 5D / 20D |
| 多空夏普 | Q10−Q1，持有 20D，年化因子 √(252/20) ≈ 3.55 |
| 样本 | 市场状态 1092 天（bull 351 / flat 564 / bear 177）；板块以股票数划分 |

| reversal_20 | +0.054 | +0.035 | +0.090 | ⚠️ 熊市显著更强 |
| bias_20 | −0.047 | −0.034 | −0.082 | ⚠️ 熊市更强 |
| corr_pv_20 | −0.048 | −0.054 | −0.082 | ⚠️ 熊市更强 |

### 多空夏普（年化）

| 因子 | bull | flat | bear | 稳定性 |
|---|---|---|---|---|
| turnover | −3.92 | −4.55 | −2.78 | ✅ 全状态强 |
| amihud_20 | +4.14 | +2.93 | +1.80 | ✅ 全状态强 |
| reversal_20 | +1.17 | +1.32 | +3.37 | ⚠️ 熊市更强 |
| corr_pv_20 | −1.80 | −2.25 | −2.79 | ⚠️ 熊市更强 |
| bias_20 | −1.31 | −1.52 | −3.12 | ⚠️ 熊市更强 |
| bp | +2.46 | +1.62 | +1.20 | ⚠️ 牛市更强 |
| ep_ttm | +2.66 | +0.96 | +0.50 | ❗ 牛市强，熊市几乎失效 |
| volatility_20 | −0.83 | −1.36 | −0.86 | ❗ 全状态偏弱 |

**结论**：
- 价量因子（turnover、amihud_20）**跨状态稳健**，可作为核心因子；
- 反转/超跌类（reversal_20、bias_20、corr_pv_20）呈**防御性**，熊市反而更好；
- 估值类（bp、ep_ttm）呈**进攻性**，牛市更强，ep_ttm 在熊市接近失效；
- volatility_20 三个状态下 |Sharpe| 均 < 1.5，是 8 个因子中最弱的一个。

## 四、板块稳健性（20D IC）

| 因子 | 主板 | 创业板 | 科创板 | 符号一致 |
|---|---|---|---|---|
| turnover | −0.099 | −0.148 | −0.085 | ✅ |
| volatility_20 | −0.076 | −0.100 | −0.050 | ✅ |
| amihud_20 | +0.055 | +0.083 | **−0.036** | ❌ 科创板反号 |
| bp | +0.059 | +0.064 | +0.041 | ✅ |
| corr_pv_20 | −0.057 | −0.068 | −0.044 | ✅ |
| reversal_20 | +0.051 | +0.068 | +0.053 | ✅ |
| bias_20 | −0.045 | −0.063 | −0.055 | ✅ |
| ep_ttm | +0.041 | +0.039 | +0.028 | ✅ |

**结论**：
- 8 个因子中 **7 个跨板块符号一致**，稳健性良好；
- **创业板 IC 普遍强于主板**（散户多、波动大、反转/换手更极端），是真实结构特征；
- **科创板 ICIR 全部偏低**（样本少：562 只股票 + 开板晚），IC 方向对但噪声大；
- **amihud_20 在科创板反号**，但 ICIR 仅 −0.19（|t| < 1），**统计上不显著**，不构成推翻其在主板/创业板有效性的证据。

## 五、因子分类与使用建议（供 M7 参考）

| 类别 | 因子 | 建议 |
|---|---|---|
| **核心稳健因子** | turnover, amihud_20 | 全状态、全板块（除科创板 amihud）均强，可作为主力因子 |
| **防御型因子** | reversal_20, bias_20, corr_pv_20 | 熊市更强，适合防御性配置或作为市场下行时的对冲 alpha |
| **进攻型因子** | bp, ep_ttm | 牛市更强，适合进攻性配置；ep_ttm 熊市慎用 |
| **待观察因子** | volatility_20 | 三状态 Sharpe 均 < 1.5，M7 中可考虑单独评估是否保留 |

## 六、已知问题与备注

1. **因子方向约定**：本报告中 IC / Sharpe 的符号遵循因子原始定义。
   例如 turnover 与未来收益负相关（高换手 → 低收益），故 IC 为负、多空 Sharpe 为负。
   M7 构建最终因子库时，可将负向因子取反，使"因子值越大 → 预期收益越高"。
2. **熊市样本量**：bear 仅 177 天，统计量波动相对更大，解读时注意。
3. **科创板样本限制**：562 只股票 + 2019-07 开板，ICIR 偏低是样本问题，不代表因子失效。
4. **数据可复现**：`market_regime.csv` 由 `build_market_regime_final.py` 生成；
   `regime_ic_summary.csv` / `regime_ls_sharpe.csv` 由 `run_regime_ic.py` 生成；
   `sector_ic_summary.csv` 由 `run_sector_ic.py` 生成；均落在 `data/processed/`（`.gitignore` 忽略）。
