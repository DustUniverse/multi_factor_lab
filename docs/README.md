## 维护规则

- 新增报告后，在本 README 和根 README 的"子目录 README 索引"中同步更新。
- 报告文件名建议使用小写英文 + 下划线，例如 `factor_combination_report.md`。
- 涉及数据的结论必须写清楚数据区间、股票池、因子版本和运行脚本。
- 阶段报告建议同步维护"验收标准对照表"，方便带教快速核对。
