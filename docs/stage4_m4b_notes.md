# M4b 回撤止损（定稿）

## 设计
- **信号源**：满仓基线日频净值 `bt_nav_lasso_horizon_all8_daily.parquet`
  （保守：实际执行仓位更低 → 真实回撤更浅 → 止损偏早触发）
- **回撤**：`dd_t = nav_t / cummax(nav)_t - 1`
- **采样**：每个调仓日 `signal_date` 取当日（或之前最后交易日）`dd`
- **规则**：`pos_m4b = clip(1 - |dd| / 0.15, 0.70, 1.0)`
  - dd > -4.5%：满仓 1.0
  - dd = -15%：压至 0.70 下限
  - **永不清仓**（下限 0.70）
- **合成**：`pos_final = min(pos_m4a, pos_m4b)`

## 参数选择依据（24 组网格扫描）
- `D ∈ {0.15, 0.20, 0.25, 0.30, 0.40, 0.50}` × `min_pos ∈ {0.0, 0.3, 0.5, 0.7}`
- 最优 `D=0.15, min_pos=0.7`：Sharpe 1.4755, MDD -17.66%
- **局限**：最优在网格边界，存在过拟合风险；Sharpe 较基线仅 +1%，统计不显著

## 旧版（滞回规则）失败复盘
- 旧规则：dd < -10% → 0.7，dd < -20% → 0.0 清仓，dd > -5% 恢复 1.0
- 结果：Sharpe 1.273，MDD **-24.86%（比基线更差）**
- 根因：① 2024-02-01 清仓 → 2 月反弹 +4.42% 完全错过；② 恢复阈值 -5% 太严，2024 全年 dd 未回到 -5%，整年 0.4~0.7 仓位
- **教训**：清仓在底部 + 恢复过慢 = MDD 反而加深
